# Site de documentation HTML — Aboni

Documentation interactive **style W3Schools** (HTML / CSS / JS).

## Ouvrir

Double-clique `index.html` ou, depuis ce dossier :

```bash
python -m http.server 4173
```

Puis ouvre `http://localhost:4173`.

## Contenu

- Révision + chapitres 1 à 13
- Exemples **Try it Yourself** (éditeur + aperçu)
- **20 QCM + 20 ateliers** par chapitre
- Traduction **FR / EN / AR** (arabe en RTL)
- Thème **clair / sombre** (mémorisé)
- Barre de progression des exercices

Les énoncés markdown (français) sont aussi dans le dossier `../exos/`.
